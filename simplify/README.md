# Simplify Skill

Behavior-preserving code simplification and readability-focused refactoring.

## Overview

This skill helps agents review and simplify code without changing behavior. It
focuses on readability, maintainability, and reducing unnecessary complexity.

## Source

Copied from [Fábio Akita's adaptation](https://github.com/akitaonrails/my-skills/tree/master/simplify) of Addy Osmani's [`code-simplification` skill](https://github.com/addyosmani/agent-skills/blob/main/skills/code-simplification/SKILL.md). Addy's [MIT license](ADDY-LICENSE) is included for the original material.

## Installation

This directory lives in Petri's `my-skills` repository. Codex currently has a separate copy under `~/.codex/skills/simplify`.
