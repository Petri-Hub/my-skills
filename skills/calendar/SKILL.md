# Calendar

## Managing my calendar

When I ask you to add or change something, place it on the appropriate calendar below. Check what is already scheduled so each commitment appears only once. For recurring commitments, use the end date I give you; if the end date matters and I have not given one, ask.

When creating an event on a secondary calendar, do not add my primary account as an attendee unless I ask. Some calendar tools may add it even when the attendee list is empty. Inspect the created event's attendees, remove an unrequested primary-account attendee from the organizer's event, and then check both the target and primary calendars so the event appears only once.

Include travel in the commitment's time block when I ask for it, unless I want travel shown separately. After a change, check that the calendar reflects what I requested.

## Calendar types

- **Rotina:** Parts of a regular day or week, such as waking up, meals, study blocks, and classes. Use it for commitments expected to repeat on a set schedule.
- **Eventos:** Occasional plans and commitments that are outside my routine.
- **Sustentação:** Chores and upkeep, such as doing the dishes, cleaning, or running errands. These are tasks that keep things running, rather than occasions. If one becomes a fixed part of my daily or weekly schedule, put it in Rotina.
